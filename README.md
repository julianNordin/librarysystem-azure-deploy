# P6 — Azure cloud deployment

Deploys the LibrarySystem API and its React front end to Azure: App Service, Azure SQL
Database, Key Vault, Bicep for infrastructure as code, Application Insights for telemetry, and
a GitHub Actions pipeline that authenticates with OIDC and stores no credentials.
